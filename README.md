## Installation
To install the dependencies, create a new conda environment with
```
conda env create --file environment.yml
```
and then run
```
conda activate lcd_clipr
```
This installs all required packages as well as the `lcd_clipr` package itself.
The results in the paper were produced on Linux (Python 3.11.6, CUDA 12.1)
with the exact package versions in `requirements-pinned.txt`.

## Data

Download the following files and move them to `data/`
at the root of this repository:

### Norman et al. (2019)

Required path: 
- `data/Norman_2019_raw.h5ad`
(download [here](https://figshare.com/articles/dataset/Normal_et_al_2019/19134071)).


### Replogle et al. (2022)

Required path: 
- `data/K562_essential_raw_singlecell_01.h5ad`
(download [here](https://plus.figshare.com/articles/dataset/_Mapping_information-rich_genotype-phenotype_landscapes_with_genome-scale_Perturb-seq_Replogle_et_al_2022_processed_Perturb-seq_datasets/20029387)).



### Wessels et al. (2023)

Required path: 
- `data/Wessels_2023/`

Download the following files [here](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE213957):
- `GSE213957_THP1-CaRPool-seq.metadata.tsv.gz`  
- `GSE213957_THP1-CaRPool-seq_and_GSE213957_HEX293FTstabRNA.tar.gz` 

Unzip both `.gz` files and move all resulting files directly in `data/Wessels_2023/`, 
including files from subfolders inside the archive. 
The folder should have a flat structure with no subdirectories.

## Results

All results are stored in `results/` at the root of the repository.

The results are generated through the script `lcd_clipr/manager.py`, which orchestrates the experiments.
We run several experiments, which are configured by separate folders in `experiments/`.
The experiment folders contain `.yaml` files that specify the 
data-loading process (`data.yaml`),
the hyperparameter grids tuned for each method (`methods_validation.yaml`), 
and the final hyperparameter config of each method (`methods.yaml`).


To reproduce the results in the paper, sequentially run the following:
```
python lcd_clipr/manager.py wessels-1000 --data --submit
python lcd_clipr/manager.py wessels-1000 --methods --submit
python lcd_clipr/manager.py wessels-1000 --summary --submit

python lcd_clipr/manager.py norman-1000 --data --submit
python lcd_clipr/manager.py norman-1000 --methods --submit
python lcd_clipr/manager.py norman-1000 --summary --submit

./scripts/linear-er.sh --data --submit
./scripts/linear-er.sh --methods --submit
./scripts/linear-er.sh --summary --submit

./scripts/linear-sfo.sh --data --submit
./scripts/linear-sfo.sh --methods --submit
./scripts/linear-sfo.sh --summary --submit

python lcd_clipr/manager.py analysis-replogle-1000 --data --submit
python lcd_clipr/manager.py analysis-replogle-1000 --methods --submit

python lcd_clipr/manager.py analysis-replogle-1000-heldout --data --submit
python lcd_clipr/manager.py analysis-replogle-1000-heldout --methods --submit

python lcd_clipr/manager.py wessels-1000-ablations --data --submit
python lcd_clipr/manager.py wessels-1000-ablations --methods --submit
python lcd_clipr/manager.py wessels-1000-ablations --summary --submit
```
The individual executions take significant time and resources
(see compute requirements for cluster in the respective configs).

#### Hyperpameter tuning
We already copied the optimal hyperparameters into the 
`methods.yaml` config files of the respective experiment folders.
To tune the hyperparameters of all methods,
we initially ran the following after the `--data` steps:
```
python lcd_clipr/manager.py wessels-1000 --methods_train_validation --submit
python lcd_clipr/manager.py wessels-1000 --summary_train_validation --submit

python lcd_clipr/manager.py norman-1000 --methods_train_validation --submit
python lcd_clipr/manager.py norman-1000 --summary_train_validation --submit
```
This generates a summary of the best hyperparameter configs for each method 
on the train/val data split.


#### Debugging
The following dummy experiment can be used to test the installation 
and debug the code (requires the `data/Wessels_2023/` data):
```
python lcd_clipr/manager.py debug --data --submit
python lcd_clipr/manager.py debug --methods --submit
python lcd_clipr/manager.py debug --summary --submit
```



## Figures 

All plots are stored at `plots/` and generated by reading the 
results of the `--methods` and `--summary` steps.

Most plots only require that summary `.csv` files are stored at `results/dumps/`.
You can collect all summary files into one `.zip` file by running `python scripts/collect_dfs.py`, 
pointing to the `results/` path on your compute infrastructure.

To regenerate the figures in the paper, run the following:
